# 豆包办公使用教程（从基础到进阶）

一份系统学习豆包办公的中文教程，覆盖**网页版 / PC 电脑版 / 手机 App** 三大入口，从认识豆包到自动化工作流，一步步带你掌握豆包的全部核心能力。

## 快速开始

直接打开 [`index.html`](./index.html) 即可在浏览器中阅读（无需联网依赖，单文件自包含）。

## 功能特色

- **三端标注**：每项功能均标注网页版 / PC 版 / 手机版支持情况
- **能力矩阵**：开篇全局速览表，一眼看清各端差异
- **示例话术**：大量可直接套用的提示词模板
- **响应式**：桌面与手机均可流畅阅读
