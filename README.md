# 豆包办公使用教程（从基础到进阶）

## 功能特色

- **三端标注**：每项功能均标注网页版 / PC 版 / 手机版支持情况
- **能力矩阵**：导读中的全局速览表，一眼看清各端差异
- **示例话术**：大量可直接套用的提示词模板
- **学习路径**：从基础到进阶的六步路线图
