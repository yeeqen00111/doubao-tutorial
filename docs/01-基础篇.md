## 3. 对话模式 vs 工作任务模式

这是豆包办公最重要的一个概念——先分清两种模式，就知道什么任务该在哪做。

| 维度 | 对话模式（快速模式） | 工作任务模式（Agent） |
| --- | --- | --- |
| 定位 | 快速问答与内容生成 | 围绕目标持续执行多步任务 |
| 过程 | 单次响应 | 拆解 → 查找 → 处理 → 交付 |
| 工具 | 基本不调用 | 搜索、文件、浏览器、技能、连接器 |
| 产物 | 文字回答 | 可继续修改的完整成果文件 |
| 适合 | 「帮我查一下…」「写一段…」「总结一下…」 | 「根据这些材料做一份15页的汇报PPT」「合并分析这些表格」「查资料并写一份行业调研报告」 |

### 各端怎么切换？

| 入口 | 切换到工作任务模式的方法 |
| --- | --- | --- |
| 手机 App | 对话界面左下角切换为「工作任务」模式（部分版本默认即为工作任务） |
| 网页版 / 电脑版 | 新建对话后，在屏幕中央切换到「工作」 |
| 豆包工作客户端 | 无需切换，打开即工作任务模式 |

> **记忆点：** 只问问题用「对话」；要豆包动手干活、交付文件，用「工作任务」。Word、PDF 等文件产物必须切换到工作任务模式；PPT 和 Excel 在对话模式也能直接生成。

## 4. 描述任务五项法：让结果更符合预期

豆包官方推荐：一次说清五项信息，任务成功率大幅提升。

1. **任务目标**：你想达成什么？用一句话说清楚结果状态。
2. **结果给谁用**：受众决定语气和深度——管理层看结论，执行层看步骤，客户看价值。
3. **需要读取的材料**：上传相关文件、提供链接，或说明可搜索的关键来源。
4. **交付格式和结构**：要 Word / PPT / Excel / 网页？多少页？分几部分？列哪些要点？
5. **验收标准**：必须满足的条件——数据要核对、篇幅要控制、风格要正式、必须有结论建议。

### 一个对比

**反面示例：**「帮我做个 PPT」

**好的示例：**

> 帮我做一份 12 页以内的季度业务汇报 PPT，面向公司管理层：先给 3 个选题方向让我选一个再展开；内容以「营收、用户、产品」三个维度为主，每页结论先行；风格简洁商务、多用图表；引用数据需标注来源。先给我大纲，确认后再生成。

> **复杂任务先要计划：** 任务较复杂时，先让豆包给出执行计划，确认后再继续；涉及对外发布、合同、财务等重要内容，交付前仍需人工复核。

> **不会描述？直接用「任务描述官」**：如果你说不清上面这五项，可以把模糊想法直接丢给豆包，用[第十三部分 · 任务描述官](./13-任务描述官.md)提供的通用提示词或安装「任务描述官」技能，豆包会按五项法帮你追问补全，输出可直接复制的完整任务描述。
