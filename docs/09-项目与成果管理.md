# 第九部分：项目与成果管理

> 学会组织你的工作任务、管理交付文件，让豆包真正成为可积累的生产力。

## 1. 用「项目」组织任务

豆包工作中的任务对话本身就是按项目组织的：每个新对话就是一个独立任务上下文。建议按项目建对话，把相关任务放一起，成果文件集中管理。

- **一项目一对话**：「Q3 市场方案」「毕业论文」「客户演示 PPT」各开一个对话，避免上下文互相干扰。
- **利用定时任务沉淀**：周期性成果（日报、周报、数据监控）用定时任务自动生成，成果自动归档。
- **云端成果多端同步**：云电脑 / 网页端生成的飞书文档、PPT 等云端成果，可在 App、网页端、电脑端之间同步查看与编辑。
- **本地文件按项目存放**：PC 客户端生成的文件建议按项目建文件夹存放，方便查找与二次编辑。

## 2. 成果文件的存放与接力

| 成果类型 | 管理与接力方式 |
| --- | --- |
| 云端成果（飞书文档 / PPT / 在线表格） | 自动同步，可在手机、网页、电脑端接力查看与编辑 |
| 本地生成文件（Word / Excel / PPT 等） | 保存到本机；本地电脑任务成果仅保存在本机，跨设备需手动传输 |
| 云电脑成果 | 任务在云端运行，关闭电脑后仍可继续，换设备也能查看进度与结果 |

## 3. 继续修改已交付的成果

豆包工作交付的文档、表格、PPT、网页或应用都可以继续修改：直接提出补充数据、调整结构、压缩篇幅或改变风格，也可以选中具体位置使用 AI 编辑定向修改，不必每次重新生成全部内容。

> **示例：** 基于上一次生成的方案，把预算部分更新为 2026 年 Q4 数据，并压缩到 8 页。
