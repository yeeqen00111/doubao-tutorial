# 第二部分：日常使用

> 以下功能三端基本都支持，标注了各端特别入口。

## 1. 普通对话与联网搜索

直接输入问题即可。需要最新信息时，可开启「联网搜索」，豆包会检索网页后回答并附来源。

- 支持端：✅ 网页版 / ✅ PC版 / ✅ 手机版

## 2. 上传附件问答

上传 Word、PDF、Excel、PPT、图片等文件，让豆包读取后总结、提取数据、对比分析。手机 App 还支持**拍图问答**：拍下文档、题目、票据，直接提问。

- 支持端：✅ 网页版 / ✅ PC版 / ✅ 手机版（含拍图）

> **示例：** 帮我总结这份 PDF 的核心观点，并提取所有关键数据做成表格。

## 3. 图片 / 视频生成

在输入框选择「图片生成」或「视频生成」，用文字描述画面即可。描述越具体（主体、风格、构图、光线）效果越好。

- 支持端：✅ 网页版 / ✅ PC版 / ✅ 手机版

> **去水印：** 订阅用户在**网页版 / 电脑版**可去除水印下载（图片右上角「…」→「AI 生成水印设置」）；移动端正在开发中。

## 4. 录音转写 / 录音纪要

实时录音并转成文字，自动生成摘要与结构化纪要，保留完整文字记录与时间戳。单次最长约 4 小时，支持后台录音。

- 支持端：❌ 网页版不支持 / ✅ PC版 / ✅ 手机版

**手机 App：** 功能栏找到「录音转写」（或「+」菜单选择）→ 允许麦克风 → 开始录音 → 结束查看结果卡片。也可以直接说「帮我开始录音」。

**电脑客户端：** 功能栏或「+」菜单中选择「录音转写」→ 授予麦克风权限（录电脑内部声音需额外授权）。

## 5. 语音 / 视频通话

三端均支持与豆包语音或视频通话，适合口语化问答、头脑风暴、陪伴练习等场景。进入对话页后点击通话按钮即可。

- 支持端：✅ 网页版 / ✅ PC版 / ✅ 手机版

## 6. 记忆功能

豆包可以记住你的偏好和关键信息（称呼、习惯、常用格式），让回答更贴合你。可随时在「设置」中查看、删除或清空记忆，也可关闭记忆功能。

- 支持端：✅ 网页版 / ✅ PC版 / ✅ 手机版

> **示例：** 以后写周报都用简洁的表格形式，称呼我「小陈」。
