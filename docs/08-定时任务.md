# 第八部分：定时任务

> 定时任务在云端到点自动执行，完成后推送结果。支持一次性、每天、每周、每月等周期。

## 1. 两种创建方式

| 方式 | 说明 |
| --- | --- |
| 自然语言创建（推荐） | 直接在工作任务中说「每天 / 每周 / 某个时间帮我做……」；用自然语言即可查看、暂停、修改、删除 |
| 页面设置 | 进入左侧导航栏「定时任务」页面，设置任务内容、执行时间、重复周期、结果接收方式 |

- 支持端：✅ 网页版 / ✅ PC版 / ✅ 手机版

> **示例：** 每周一上午9点，整理上一周的行业动态并生成简报。

## 2. 稳定的定时任务需要五个要素

定时任务的重点不是只写时间。每次执行都需要相同的范围和规则，否则同一句「帮我做日报」可能得到不同结果。

| 要素 | 示例 | 说明 |
| --- | --- | --- |
| 时间 | 每个工作日 9:00 | 写清时区、工作日/自然日、是否有截止日期 |
| 任务内容 | 收集昨日全网行业新闻 | 越具体，每次执行越稳定 |
| 处理方式 | 提炼重点、按主题分类 | 固定处理规则，结果才一致 |
| 输出格式 | 生成 500 字简报，表格附关键数据 | 固定交付结构 |
| 结果接收 | 推送到飞书群 / 对话 | 明确在哪里收到结果 |

## 3. 管理定时任务

- **查看**：在「定时任务」页面查看执行状态、历史记录和下次执行时间。
- **修改 / 暂停 / 删除**：随时操作，也可在对话中用自然语言说「暂停这个周报任务」「把时间改到下午3点」。
- **立即执行**：需要时手动触发一次，不等下次计划。

> **示例：** 每天上午 10 点，收集 AI 行业过去 24 小时的热点新闻，提炼 3 条最重要的，用简洁格式发到我的对话里。

> **额度提示：** 定时任务每次运行都会消耗额度。如发现额度异常减少，可在「定时任务」页面检查并终止不需要的任务。
