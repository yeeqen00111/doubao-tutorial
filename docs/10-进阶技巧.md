# 第十部分：进阶技巧

> 把前面的能力组合使用，豆包就从「助手」变成「自动化工位」。

## 1. 学习路径：一步一步来

| 步骤 | 目标 | 内容 |
| --- | --- | --- |
| 第 1 步 | 会用对话 | 问答、搜索、写作、附件分析 |
| 第 2 步 | 会出成果 | AI PPT、AI 表格、图片视频生成 |
| 第 3 步 | 会用任务模式 | 拆解任务、上传材料、交付文件、继续修改 |
| 第 4 步 | 会用扩展能力 | 技能、连接器、工作伙伴、小队协作 |
| 第 5 步 | 会自动化 | 定时任务 + 技能 + 连接器，无人值守运转 |
| 第 6 步 | 会协同与沉淀 | 飞书协作、云电脑接力、项目成果管理 |

## 2. 三组进阶组合拳

### 日报自动化

1. 定时任务：每工作日 9:00
2. 连接器：接入数据源 / 群聊
3. 技能：日报生成技能
4. 结果：自动推送到对话或飞书

### 调研报告小队

1. 数据伙伴：收集与分析数据
2. 研究伙伴：搭建分析框架
3. 设计伙伴：制作可视化图表
4. 成果：一份完整调研报告

### 跨设备接力

1. 手机发起：随手布置任务
2. 云电脑执行：后台持续运行
3. 电脑精修：打开成果继续编辑
4. 任意端查看：进度结果随时同步

## 3. 安全与使用边界

- 涉及删除、发布、发送或修改关键数据的操作，执行前确认目标和范围。
- 对外发布、合同、财务等重要内容，务必人工复核后再使用。
- 连接器只在授权账号的权限范围内操作，不越权、不索取敏感凭证。
- 定时任务消耗额度，及时清理不需要的任务。
