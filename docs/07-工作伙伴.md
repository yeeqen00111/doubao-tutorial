# 第七部分：工作伙伴与工作小队

> 工作伙伴是预置或自定义的专业 AI 角色，相当于负责不同工作的同事。

## 1. 官方伙伴覆盖领域

| 领域 | 说明 |
| --- | --- |
| 内容创作 | 文案、脚本、文章创作类伙伴 |
| 办公提效 | 文档、汇报、会议纪要类伙伴 |
| 产品研发 | 产品、开发、测试类伙伴 |
| 数据分析 | 数据分析、可视化类伙伴 |
| 学习教育 | 学习、辅导、研究类伙伴 |

## 2. 怎么用工作伙伴？

- 支持端：🕐 网页版以页面为准 / ✅ PC版支持 / 🕐 手机版以页面为准

1. **进入伙伴专区**：电脑版侧边栏「技能 · 连接器 · 伙伴」→ 工作伙伴专区。
2. **选择或创建伙伴**：使用官方伙伴，或根据业务自定义伙伴的知识、工作方法和可调用能力。
3. **为伙伴配置能力**：给伙伴挂上需要的技能和连接器，增强其专业能力。
4. **组建小队分工协作**：多个伙伴组成小队，把复杂任务拆成子任务并行或接力完成，如「数据调研报告」联动数据、研究、设计类伙伴。
5. **过程可控**：查看各伙伴执行过程，可补充要求或中途纠偏。

> **示例：** 用数据伙伴收集行业数据、研究伙伴写分析框架、设计伙伴做可视化图表，一起完成这份市场调研报告。
