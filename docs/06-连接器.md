# 第六部分：连接器

> 连接器是豆包对接外部系统和数据源的工具。完成授权后，豆包能在权限范围内读取信息或执行操作。

## 1. 连接器能做什么？

| 场景 | 说明 |
| --- | --- |
| 企业信息 | 接入企业系统，读取业务数据、组织信息 |
| 出行 / 地图 | 查路线、规划行程、天气信息 |
| 快递 | 查询物流状态、跟踪包裹 |
| 开发工具 | 代码仓库、CI、部署等开发链路接入 |
| 第三方协同 | 对接外部协作平台，读取或操作授权数据 |
| 自有服务 | 对接你自己的业务系统与数据服务 |

## 2. 怎么使用连接器？

- 支持端：🕐 网页版以页面为准 / ✅ PC版支持 / 🕐 手机版以页面为准

1. **进入连接器专区**：电脑版侧边栏「技能 · 连接器 · 伙伴」→ 连接器专区。
2. **安装并授权**：选择需要的连接器安装，按提示完成账号授权（授权范围以连接账号的权限为准）。
3. **在任务中调用**：回到工作任务对话，自然语言提出需求，豆包会在授权范围内读取信息或执行操作。

> **示例：** 帮我查一下包裹【单号】的物流到哪了，并预测预计送达时间。

> **权限边界：** 连接成功不代表拥有全部权限，实际可用范围取决于所连接账号、授权操作和资源本身的权限。涉及敏感数据的操作，请在执行前确认范围。
