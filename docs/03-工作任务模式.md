# 第三部分：工作任务模式（豆包工作）

> 这是豆包办公的核心。理解它，你就从「用 AI 问答」升级为「让 AI 干活」。

## 1. 什么是豆包工作（Agent）

豆包工作（工作任务模式）是豆包面向生产力场景推出的 Agent 产品。你只需说明想完成什么，它会**围绕目标拆解任务、调用工具、持续执行**，把想法变成文档、表格、PPT、图片、视频、网页或系统等可交付成果。

### 它能做什么

| 能力 | 说明 |
| --- | --- |
| 写文档做表格 PPT | 基于目标与材料生成 Word、PDF、Excel、PPT，并可继续修改 |
| 搜索研究 | 深度研究、资料整理、数据分析与可视化 |
| 操作浏览器电脑 | 授权范围内操作浏览器和电脑，过程可见、可暂停、可接管 |
| 飞书协作 | 查会议结论、总结群聊、制定方案、生成周报（飞书账号登录） |
| 技能连接器 | 调用技能、连接器、工作伙伴扩展专业能力与自动化流程 |
| 定时任务 | 云端到点自动执行，日报周报、监控、流程自动化 |

### Agent 和普通聊天的区别

| 维度 | 普通聊天 | 工作任务模式（Agent） |
| --- | --- | --- |
| 定位 | 快速问答与内容生成 | 围绕目标持续执行多步任务 |
| 过程 | 单次响应 | 拆解 → 查找 → 处理 → 交付 |
| 工具 | 基本不调用 | 搜索、文件、浏览器、技能、连接器 |
| 产物 | 文字回答 | 可继续修改的完整成果文件 |

- 支持端：✅ 网页版 / ✅ PC版 / ✅ 手机版（入口：App 左下角切换；网页/电脑新建对话后中央切「工作」）

## 2. 本地电脑 vs 云电脑：怎么选？

任务在哪里执行，直接影响能访问什么资源、关电脑后任务是否继续。

| 维度 | 本地电脑 | 云电脑 |
| --- | --- | --- |
| 资源访问 | 访问本机文件、软件、浏览器登录态 | 云端独立环境，不能直接访问本机未上传文件 |
| 运行条件 | 需电脑开机联网、客户端在线 | 不占本机资源，关网页、合电脑、换设备任务继续 |
| 性能占用 | 占用一定本机资源 | 多任务可并行，不拖慢本机 |
| 适合场景 | 读本地文档做 PPT、操作本机浏览器、整合本机文件 | 公司电脑配置低、批量并行、需持续运行的自动化 |

### 场景选择速查

| 场景 | 推荐 | 原因 |
| --- | --- | --- |
| 处理本机文件 | 本地电脑 | 直接读取本地文档，免上传 |
| 用本机软件 / 登录态 | 本地电脑 | 可调用本机已装的软件和浏览器登录 |
| 公司电脑配置低 | 云电脑 | 任务在云端跑，不拖慢本机 |
| 批量并行 / 长任务 | 云电脑 | 多任务独立运行、关电脑不中断 |
| 多端接力（手机↔电脑） | 云电脑 | App / 网页 / 电脑端进度与成果同步 |

> **边界：** 云电脑与本地电脑相互隔离，云电脑不能访问未上传的本机文件，也不能复用本机软件和浏览器登录态。网页端选择云电脑时同样无法读取本机文件——这类任务请用 PC 客户端 + 本地电脑。

## 3. 交付成果与继续修改

豆包工作的价值不只是「生成」，而是生成后还能继续改。

### 常见产物与适用场景

| 产物 | 适用场景 | 建议说明 |
| --- | --- | --- |
| Word / 文档 | 方案、报告、制度、说明书、会议材料 | 说明受众、篇幅、结构和语气 |
| Excel / 表格 | 数据整理、合并分析、台账、统计报表 | 说明数据来源、表结构和计算口径 |
| PPT | 汇报、提案、培训、路演 | 说明页数、风格、听众和每页要点 |
| PDF | 正式发布、对外交付、留档 | Word 等生成后可另存为 PDF |
| 图片 / 视频 | 配图、海报、短视频、宣传素材 | 描述风格、比例、文案和用途 |
| 网页 / 应用 | 信息页、工具站、可视化看板 | 说明功能、页面结构和视觉风格 |

> **交付形式：** 文件产物（Word / PDF / Excel / PPT）用 PC 客户端体验最佳——可直接读取本机文件、结果保存到本地继续编辑。云电脑与网页端的成果可在多端同步查看。

### 生成后怎么继续改？

1. **直接提出修改要求**：「补充第三季度数据」「压缩到10页」「语气改正式一些」「换成深色模板」——豆包基于原成果定向修改，不必重来。
2. **AI 编辑选中位置**：在生成的文档 / PPT / 网页中选中具体位置，使用 AI 编辑功能定向修改局部内容。

> **示例：** 刚才的 PPT 里，把第 5 页的产品对比表格换成竖版排版，并把结论加粗放在页面顶部。
