# 常见问题 FAQ

## 1. 免费版和豆包订阅有什么区别？

免费版可使用普通对话、搜索、写作；高级功能（图片视频生成、AI PPT、任务模式、录音纪要等）每日有免费次数，用完次日重置。订阅版拥有更大月度额度池、高峰期优先使用权、最新模型与更多定时任务。各档位额度：加强套餐是标准的 4 倍，高级套餐是标准的 10 倍。

## 2. Word / PDF 怎么生成？

Word、PDF 等依赖 Agent 执行和交付文件的产物，需要切换到「工作任务」模式。PPT 和 Excel 在快速模式（对话模式）中也能直接生成，说清内容、受众和格式要求即可。

## 3. 豆包账号和飞书账号有什么区别？

豆包账号对应个人身份、个人空间与个人订阅权益，适合处理公开资料、本地文件与个人任务；飞书账号对应企业身份与组织权限，可在授权范围内使用企业知识与协作能力。两个账号的数据、权益和权限不会自动合并。

## 4. 生成的文件还能改吗？

可以。直接提出补充数据、调整结构、压缩篇幅或改变风格，或选中具体位置用 AI 编辑定向修改，不必每次重新生成。

## 5. 我的额度怎么变少了？

高级功能（视频生成、任务模式、AI PPT、深度思考、视频通话等）都会消耗额度；开启了定时任务时，每次运行也会消耗。可在「设置 → 豆包订阅 → 订阅与额度管理」查看剩余比例，并在定时任务页面终止不需要的任务。

## 6. 公司电脑配置低，能用豆包工作吗？

可以。直接在豆包网页端选择云电脑运行任务，不占用本机性能、无需安装完整工作环境。但网页端云电脑无法直接读取本机文件、使用本机软件或访问企业内网，这类任务需使用电脑版 + 本地电脑。
