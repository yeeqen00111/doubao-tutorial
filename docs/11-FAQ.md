# 常见问题 FAQ

## 1. 免费版能做什么？有什么限制？

免费版可使用普通对话、搜索、写作，不限次数；高级功能（图片视频生成、AI PPT、任务模式、录音纪要等）每日有免费次数，用完当日暂停、次日重置。本教程覆盖的所有功能免费版均可使用。

## 2. Word / PDF 怎么生成？

Word、PDF 等依赖 Agent 执行和交付文件的产物，需要切换到「工作任务」模式。PPT 和 Excel 在快速模式（对话模式）中也能直接生成，说清内容、受众和格式要求即可。

## 3. 豆包账号和飞书账号有什么区别？

豆包账号对应个人身份、个人空间与个人权益，适合处理公开资料、本地文件与个人任务；飞书账号对应企业身份与组织权限，可在授权范围内使用企业知识与协作能力。两个账号的数据、权益和权限不会自动合并。

## 4. 生成的文件还能改吗？

可以。直接提出补充数据、调整结构、压缩篇幅或改变风格，或选中具体位置用 AI 编辑定向修改，不必每次重新生成。

## 5. 免费次数用完了怎么办？

图片视频生成、AI PPT、任务模式等高级功能的每日免费次数用完，对应功能当日暂停，次日（自然日）重置后恢复。可在「设置 → 豆包订阅 → 订阅与额度管理」查看剩余比例；如果开启了定时任务，每次运行也会消耗免费次数，不用的任务及时终止。

## 6. 公司电脑配置低，能用豆包工作吗？

可以。直接在豆包网页端选择云电脑运行任务，不占用本机性能、无需安装完整工作环境。但网页端云电脑无法直接读取本机文件、使用本机软件或访问企业内网，这类任务需使用电脑版 + 本地电脑。
