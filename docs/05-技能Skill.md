# 第五部分：技能（Skill）

> 技能是封装了特定领域知识、标准流程和工具用法的高质量能力模块，让豆包更稳定地完成专业任务。

## 1. 技能分两类

| 类型 | 说明 |
| --- | --- |
| 平台内置技能 | 运行时原生提供、无需安装，覆盖办公协作、编程、互联网、新媒体创作等 |
| 豆包推荐技能 | 覆盖金融、法律、新媒体创作、互联网、编程、学术、电商、医疗、办公协作、出行生活等，需在技能专区安装后使用 |

## 2. 怎么使用技能？

- 支持端：🕐 网页版以页面为准 / ✅ PC版完整支持 / 🕐 手机版以页面为准

1. **进入技能专区**：打开豆包**电脑版**（网页端 / 客户端），在侧边栏找到「技能 · 连接器 · 伙伴」。
2. **浏览与安装**：在豆包技能专区中浏览推荐技能，点击安装后即可使用。
3. **回到对话使用**：安装后在对话中直接提出需求，豆包会自动匹配并调用相应技能；也可在对话中点选技能图标指定使用。

## 3. 如何新建自己的技能？

1. **技能面板右上角新建**：在技能专区点击「新建技能」，把常用工作步骤、交付标准和参考模板整理成可复用的流程。
2. **对话中让豆包帮你创建**：直接在工作任务对话中描述你的流程，让豆包帮你封装成技能。

> **示例：** 帮我创建一个「周报生成」技能：每周五读取我提供的本周工作记录，按「本周完成 / 数据亮点 / 下周计划 / 风险问题」四段生成周报，输出简洁表格形式。
